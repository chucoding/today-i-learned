# Superpowers

곧장 코드로 뛰어드는 대신 질문을 통해 아이디어를 먼저 다듬는 과정을 시작하고, 계획 → 실행 → 검증 순서를 강제하는 스킬

- 핵심 철학: 테스트 우선, 추측보다 프로세스, 그리고 성공 선언 전에 검증하기

## 장점

- TDD, 계획 주도 설계 등을 매번 명령하지 않고 자동화 가능

## 단점

- 간단한 수정에도 브레인스토밍, 계획 단계를 거치면 오히려 느려질 수 있음.
- 최신 모델일수록 이런 습관을 어느 정도 내재화하고 있어서, 무거운 프레임워크의 효용이 점점 줄어듦.

## 브레인스토밍

코드를 쓰기 전에 선택지, 트레이드오프, 수용 기준을 정리해주는 스킬

- Superpowers에서 끝까지 남겨두는 스킬로 가장 자주 언급됨.
- 사용자가 머릿속에만 가지고 있는 의도를 끌어내는 일은 모델이 아무리 똑똑해져도 대신할 수 없음.
- Superpowers 전체 흐름에 묶여 있기 때문에 단독으로 쓰려면 다른 스킬들을 off 해야 함.

## Superlite

Superpowers를 바탕으로, 반복 승인과 순차 실행을 줄인 플러그인

### 특징

- 명세를 넘기면 계획부터 병렬 구현, 테스트와 리뷰까지 진행
- 계획 승인 또는 자동화 방식 선택 가능
- 단계마다 사람이 관여하려면 Superpowers, 명세를 맡기고 자율 실행하려면 Superlite가 적합.
- 자체 벤치마크에서 Superpowers보다 실행 시간이 52% 짧았음.
