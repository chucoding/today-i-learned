# `/qa-only`

SPA 현업에서 가장 자주 사용하는 스킬

## 적합한 변경

- 폼 입력 · 저장 · 유효성 검사
- Grid 정렬 · 필터 · 편집 · 페이지네이션
- 모달 · Drawer · 탭
- 라우팅과 뒤로가기
- 권한별 UI
- API loading / error / empty
- 캐시 갱신 후 화면 반영
- 모바일 · 반응형
- 콘솔 오류 · 중복 요청

## 왜 필요한가

SPA에서는 build와 유닛 테스트가 통과해도 다음 문제가 자주 남음

- 저장 후 목록이 갱신되지 않음
- 탭 이동 후 이전 필터가 남음
- 뒤로가기 시 폼 상태가 사라짐
- 빠르게 두 번 클릭하면 요청이 중복됨
- 에러 토스트와 오류 페이지가 동시에 표시됨
- Grid 선택 상태가 잘못 복원됨

이런 문제는 `/qa-only`가 가장 잘 다루는 영역
