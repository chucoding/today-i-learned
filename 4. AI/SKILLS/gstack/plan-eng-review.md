# `/plan-eng-review`

복잡한 기능에만 선택적으로 사용. 매 Jira 티켓마다 사용할 필요 없음

## 사용 기준

다음 조건 중 두 개 이상이면 사용

- 여러 화면이나 업무 영역에 영향
- API 계약 변경
- 서버 상태와 클라이언트 상태가 함께 변경
- 권한 · 저장 · 캐시 · 동시성 포함
- 공통 컴포넌트 API 변경
- 마이그레이션 또는 점진적 배포 필요
- 실패 시 데이터 정합성 문제 발생
- 두 가지 이상의 설계 대안 존재

## 적합한 예

- 공통 Grid 저장 API 개편
- 여러 탭이 공유하는 편집 상태
- 낙관적 업데이트와 롤백
- 화면 권한 체계 변경
- 대규모 폼과 임시 저장
- 공통 오류 처리 구조 변경

## 생략해도 되는 예

단순 버튼 · 컬럼 · 모달 추가
