# ChatGPT 프롬프트 엔지니어링

## Best Practice
### 1. 최신 모델 사용하기
- 새로운 모델일수록 지시를 이해하고 따르기 쉬운 경향이 있음
- 단, 추론 모델과 일반 GPT 모델은 적합한 프롬프트 방식에 차이가 있을 수 있다

### 2. 지시문을 프롬프트 앞부분에 배치하기
- 해야 할 일을 먼저 적고, 실제 입력 자료는 `###` 또는 삼중 따옴표(`"""`) 같은 구분자로 분리

### 3. 원하는 출력 형식을 예시로 보여주기
```
회사명: <쉼표로 구분된 목록>
인물명: <쉼표로 구분된 목록>
세부 주제: <쉼표로 구분된 목록>
전체 주제: <쉼표로 구분된 목록>
```

### 4. 제로샷 → 퓨샷 → 미세 조정 순서로 시도하기
- 제로샷 : 예시 없이 지시
- 퓨샷 : 몇 개의 입출력 예시를 제공

### 5. 하지 말아야 할 것뿐 아니라 대신 할 일을 알려주기
단순히 “사용자 이름이나 비밀번호를 묻지 마세요”라고 쓰기보다, 개인정보를 요구하지 않고 문제를 진단하며 필요한 경우 도움말 문서로 안내하라고 지시하는 편이 좋음.
