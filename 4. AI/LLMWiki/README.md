# LLM Wiki

에이전트용 지식 저장소

## 목차

- [정의](#정의)
- [참고자료](#참고자료)

## 정의

- 에이전트가 참고할 지식(도메인, 근거, 규칙)을 저장소 문서로 쌓아 둔 위키.
- 에이전트가 필요할 때 검색(MCP 등)으로 꺼내 읽음.
- 사람이 읽는 위키와 달리 라우팅 문서(`index.md`)와 메타데이터(키워드, 별칭)로 검색에 걸리게 관리함.

> [!NOTE]
> **Skill과의 차이점**
>
>
> |         | LLM Wiki        | Skill                                     |
> | ------- | --------------- | ----------------------------------------- |
> | 닿는 방식   | 에이전트가 판단해 당겨 읽음 | `description`이 상주하다 작업 순간 자동 로드           |
> | 담는 것    | 근거와 기준(왜)       | 실행 지침(어떻게)                                |
> | 컨텍스트 비용 | 호출 전 0          | 설명은 상주, 본문은 호출 시                          |
> | 범위      | 호출할 때만 읽힘       | 사용자 전역에 두면 무관한 프로젝트에도 로드됨. 프로젝트 범위로 한정 필요 |
>
>
> - 함께 쓰는 법 : 스킬은 얇게(트리거 + 체크리스트 + 위키 포인터), 상세는 위키에.
