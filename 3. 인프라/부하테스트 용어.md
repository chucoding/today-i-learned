# 부하테스트 용어

## p95

요청을 빠른 순으로 줄 세웠을 때 **95번째 값**이다. 100번 중 95번은 그보다 빠르고 5번은 그보다 느리다. p90, p99도 같은 방식이다.

### 평균 대신 쓰는 이유

평균은 느린 소수를 묻어 버린다. 요청 100번 중 90번이 200ms, 10번이 3초라고 하면 이렇게 갈린다.


| 값   | 결과      | 읽히는 말              |
| --- | ------- | ------------------ |
| 평균  | 480ms   | 괜찮다                |
| p95 | 3,000ms | 열 명 중 한 명은 3초 기다린다 |


### 어디서 보나

JMeter Summary Report가 `90% Line`, `95% Line`, `99% Line`으로 바로 뽑아 준다.
