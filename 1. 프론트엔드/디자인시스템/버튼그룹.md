## 공통 원칙

> 💡 강조 단계(emphasis)란?
> 채움, 테두리, 텍스트처럼 버튼 모양의 시각적 무게로 액션의 우선순위를 나누는 단계.

- 주 버튼(primary)은 페이지나 영역당 1개
  > "Each page should have only one primary button."
  >
  > 출처: [Button – Carbon Design System](https://carbondesignsystem.com/components/button/usage/)
- 위험 액션의 빨강은 아껴 씀.
  - Primer: 위험 액션 버튼은 드물게 씀. 원문은 [위험 액션](#위험-액션)에 있음.
- 버튼이 많으면 overflow 메뉴로 묶음.

  > 💡 overflow 메뉴란?
  > 화면에 다 놓지 못한 액션을 `More actions`나 `⋯` 같은 버튼 하나 아래 목록으로 모아 둔 메뉴.

  - Polaris: 페이지 헤더의 나머지 액션이 많으면 More actions로 묶음.
  - Carbon: 액션이 세 개를 넘으면 메뉴 버튼으로 묶음.
  > "Any more than three actions should be grouped meaningfully using menu buttons"
  >
  > 출처: [Button – Carbon Design System](https://carbondesignsystem.com/components/button/usage/)

## 보조 액션 스타일

- 테두리(outlined) 버튼은 위험 전용이 아니라 중립적인 중간 강조
  - Material 2: 중요하지만 주 액션은 아닌 액션에 쓰는 중간 강조 버튼.
  - Ant Design: default 버튼(흰 바탕 테두리)은 우선순위 없는 일련의 액션용.
  > "Default button: used for a series of actions without priority."
  >
  > 출처: [Button - Ant Design](https://ant.design/components/button)
- 회색 채움과 테두리 모두 업계에 있음.
  - Carbon secondary는 채움 계열.
- 위험 여부는 버튼 모양(채움, 테두리)과 별개인 표시
  - Ant Design: `danger`는 버튼 종류가 아니라 어느 종류에나 붙는 속성.
  > "`danger`: used for actions of risk, like deletion or authorization."
  >
  > 출처: [Button - Ant Design](https://ant.design/components/button)

## 위험 액션

- Primer: 아껴 쓰고 보통 확인 창을 띄움.
  > "Used sparingly for destructive actions, typically prompt a confirmation dialog."
  >
  > 출처: [Button | Primer](https://primer.style/product/components/button/)

  > 💡 tertiary, ghost란?
  > Carbon의 낮은 강조 단계 버튼. tertiary는 테두리만 있는 버튼, ghost는 테두리 없이 텍스트만 있는 버튼.

- Carbon: danger는 primary, tertiary, ghost 세 스타일. 여러 액션 중 하나면 낮은 강조(tertiary, ghost)
  - 중립 tertiary와 danger tertiary를 나란히 두는 조합은 피함.
  > "Do not use tertiary and danger tertiary buttons together."
  >
  > 출처: [Button – Carbon Design System](https://carbondesignsystem.com/components/button/usage/)
- Polaris: secondary 액션에 destructive(위험 표시) 속성을 붙이고, 되돌리기 어려우면 확인 창

## 디자인 시스템별 비교

| 디자인 시스템 | 보조 액션 | 위험 액션 | 주 버튼 수 |
| --- | --- | --- | --- |
| Material 2 | 테두리 = 중간 강조 | - | 강조 단계로 위계 |
| IBM Carbon | tertiary = 낮은 우선순위 | danger(primary, tertiary, ghost) | 페이지당 1개, 4개 이상이면 메뉴 |
| Ant Design | default = 우선순위 없는 액션 | `danger`는 종류가 아니라 속성 | 구역당 최대 1개 |
| Salesforce Lightning | neutral이 기본 variant | destructive | brand가 페이지 주 액션 |
| GitHub Primer | default = 일반 액션 | danger, 보통 확인 창 | 그룹당 1개, 페이지에도 드묾 |
| Shopify Polaris | 헤더 주 액션 외 secondary, 많으면 More actions | secondary에 destructive 표시 | 1개 |
| Atlassian | - | - | 페이지나 영역당 1개 |
