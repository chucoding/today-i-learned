## 값을 골라 확정하면 라디오
- Carbon Data table : 단일 선택은 라디오 컨트롤로 한다. 컨트롤은 행 왼쪽에 둔다

  > The data table also supports a single-select radio button control, limiting the user to selecting only one row at a time.

- PatternFly Table : 한 행만 고를 수 있으면 라디오다

  > Radio button: Enables a user to select a single row at a time. Use when only 1 row can be selected at a time.

- NN/g : 하나만 고르면 라디오, 0개부터 전부까지 고를 수 있으면 체크박스

  > Amongst a list of radio buttons, only one button may be selected at a time.

- 두 디자인 시스템 모두 **컨트롤 없이 행 클릭만으로 고르는 방식은 정의하지 않는다**

> 💡 공통 그리드에 체크박스 컬럼만 있고 라디오 컬럼이 없으면, 화면마다 강조 방식으로 우회하기 쉽다. 라디오 컬럼을 그리드 기능으로 두는 편이 일관성을 지키기 쉽다.

## 마스터-디테일이면 행 강조
화면을 목록(마스터)과 고른 항목의 상세(디테일)로 나눈 구성이다. PatternFly는 primary-detail, 다른 곳에서는 list-detail이라고도 부른다. 메일함이 대표 예다.

```
┌──────────────────┬───────────────────────────┐
│ 받은 편지함       │ 주간 회의 안내             │
│──────────────────│ 보낸 사람: 팀장            │
│   배포 일정 공유   │                           │
│ ▶ 주간 회의 안내  │ 이번 주 회의는 목요일로     │
│   휴가 신청 승인   │ 옮깁니다...               │
└──────────────────┴───────────────────────────┘
   강조 = 지금 오른쪽에 보이는 항목
```

- PatternFly는 상세 영역을 채우는 항목에 선택 상태를 요구한다. 여기서 행 강조는 **정상**이다

  > There needs to be a selected state for the primary item (row or card) currently populating the details pane.

- 확정 버튼이 없다. 고르는 순간 상세가 바뀌므로 강조는 입력값이 아니라 위치 표시다
- WAI-ARIA listbox도 단일 선택에서 포커스를 따라 선택이 옮겨 가는 방식을 허용한다. 다만 상황에 따라 접근성을 크게 해칠 수 있다고 경고한다

  > In a single-select listbox, moving focus may optionally unselect the previously selected option and select the newly focused option. This model of selection is known as 'selection follows focus'. Having selection follow focus can be very helpful in some circumstances and can severely degrade accessibility in others.

## 색만으로 표시하지 않는다
어느 쪽이든 **배경색만으로 선택을 표시하면 안 된다.**

- WCAG 1.4.1 Use of Color (Level A) : 색을 유일한 시각 수단으로 쓰지 않는다

  > Color is not used as the only visual means of conveying information, indicating an action, prompting a response, or distinguishing a visual element.

- 강조에는 테두리, 아이콘(위 그림의 `▶`), 라디오처럼 색 외 표시가 함께 있어야 한다
- 선택 모달에서는 라디오 자체가 색 외 표시 역할을 하므로 이 문제가 같이 풀린다
